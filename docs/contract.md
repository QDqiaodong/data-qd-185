# 一位同步逻辑回放 v1

使用者为数字逻辑教学测试数据整理人员。输入1..64个ASCII输入网名、0..200个门、0..64个D触发器、1..64个观测输出及1..1000条向量。网名[A-Za-z_][A-Za-z_0-9]{0,63}，输入/门id/触发器id不得同名（单驱动）；常量引用"0"/"1"/"X"内置，不可被网名覆盖。门支持BUF/NOT（一入）、AND/OR/XOR/NAND/NOR（二入），args可引用输入、门、触发器或常量；未知引用、组合环拒绝。触发器有id、d、initial；经触发器的反馈允许，不属于组合环。

每条向量有唯一id、完整inputs映射和expect子集，按列表输入顺序回放（id不决定顺序）；电平必须为字符串"0"/"1"/"X"，expect可用"*"表示不比较，未列出的输出也不比较。门采用保守三值逻辑：AND中0支配未知，OR中1支配未知，NOT(X)=X，XOR若任一X则X（不做同网相关的符号化简）。

一个cycle的时序是：装载该行输入和当前触发器状态→拓扑组合求值→观测/比较边沿前输出→同时采样所有D并更新所有触发器。不能边更新边采样；下周期才看到新状态。没有异步reset、enable、实际纳秒时序、四值Z、延迟竞争或元稳态。initial只是首周期之前的值。trace保留每周期边沿前和边沿后状态，最终状态与最后一行after一致。

expected="X"要求实际也为X，不能当作don't care；不匹配记录期望、实际、向量身份和0起cycle，属于有效业务结果，CLI退出0并标all_expected_match=false。结构/值/输出文件错误退出2。gate_activity仅统计实际门输出集合，以及相邻cycle均已知且0/1变化的次数；不把经X变化计为已知翻转，不宣称完整故障覆盖或切换功耗。保留确定性门拓扑顺序作为复算线索。

全部验证后回放并原子新建JSON；已有目标（含符号链接）不覆盖。没有HDL解析、FPGA综合、硬件设备访问或随机测试向量生成。
